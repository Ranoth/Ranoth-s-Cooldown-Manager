# Ranoth's Cooldown Manager

![GitHub release (latest by date)](https://img.shields.io/github/v/release/Ranoth/Ranoth-s-Cooldown-Manager)

## Overview

Ranoth's Cooldown Manager is an extension to Blizzard's Cooldown Manager.
It emulates what a pre-Midnight central class WeakAura could look like while keeping a functionality consistent with Blizzard's default interface.

## Features

The addon will stack cooldown viewers and resource bars together, anchoring them to the Essentials viewer. You will be able to organize the positions of viewers and bars in the stack.

You can keep the looks of icons and resource bars except for the class resource bar default but you also have a few skinning options available for additional customization.

As a bonus, you have a charges counter on the Healthstone and you can track spells, equipped items and bag items that are not available inside of the default Blizzard interface using the Custom Trackers menu.

> I have not tested this addon for other classes than my own. Although it should work for other classes as well, your experience may vary.
